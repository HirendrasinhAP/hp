# Prof. Hirendrasinh Padhiyar — Academic & Research Portfolio

A responsive, multi-page static website designed for GitHub Pages.

## Included pages
- `index.html` — Home
- `about.html` — Profile, qualifications and animated career timeline
- `research.html` — Research themes
- `projects.html` — Research and innovation case studies
- `publications.html` — Searchable journal papers, book chapters and conference contributions
- `patents.html` — Searchable register of 12 published Indian patent applications
- `collaboration.html` — Research collaboration page
- `facilities.html` — Methods, technical competencies and facilities disclosure
- `updates.html` — Research notes / blog starter page

## Publish on GitHub Pages
1. Create a GitHub repository named `YOUR-USERNAME.github.io` (or any repository name if you will use a project Pages URL).
2. Upload the contents of this folder to the repository root. Keep `assets/`, `data.js`, `main.js`, `style.css` and the HTML files together.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for the Pages deployment to complete. Your site will be available at `https://YOUR-USERNAME.github.io/`.

No build step, server, database or paid hosting is required.

## Update content
- Edit page content in the relevant `.html` file.
- Edit publication, book-chapter, conference and patent records in `data.js`.
- Replace `assets/portrait.jpg` with an updated portrait if needed.
- Replace `assets/hp-logo.png` with the approved HP logo.
- The site uses Aptos as the preferred system font with standard sans-serif fallbacks. No font file is bundled.

## Academic accuracy and privacy
- Portfolio counts are separated: 10 journal/conference-series papers, 5 book chapters and 7 conference contributions as individually listed in the supplied CV. The CV summary separately states 17 scholarly outputs; this discrepancy should be reconciled before changing the headline count.
- Patent entries are identified as published applications, not granted patents.
- The downloadable `academic-cv-public.pdf` omits residential address, date of birth and personal mobile number from the source CV.
- Project pages distinguish CV-listed work from the BioResource portfolio initiative. Validate current project stage, funding status, awards and institutional associations before external claims.
- Facilities page lists tools and research capability areas from the CV; it does not claim ownership or guaranteed availability of specific instruments.
- Check the email address spelling and current contact details before public launch.

Open `index.html` in a browser. For best results, use a simple local static server or the GitHub Pages preview after publishing.
